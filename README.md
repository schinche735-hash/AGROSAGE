# AgriSage — Smart Crop Disease Detection

A farmer-friendly web app for crop-leaf disease screening with English, Hindi and Marathi interface, disease reference images, cached guidance, and a trained MobileNetV2 model.

## Run locally with VS Code

**Requirements:** Git, Python 3.11 or 3.12, and VS Code. The first run needs an internet connection to install Python packages.

1. Clone the project:

   ```bash
   git clone https://github.com/samir-deshmukh/sush.git
   cd sush
   ```

2. Open the `sush` folder in VS Code.
3. Press **Ctrl+Shift+B** and select **AgriSage: Run (automatic setup)**.
4. When the terminal says the app is running, open **http://127.0.0.1:5000**.

The setup script creates a private `.venv`, installs dependencies, and creates `.env` from `.env.example` when needed. Keep the terminal open while using the app. Press **Ctrl+C** to stop it; run `bash setup.sh` again to start it later. Installed packages are reused.

You can also start the app from a terminal with:

```bash
bash setup.sh
```

No Docker is needed for local development or the configured Render deployment.

## Deploy on Render (not deployed automatically)

The `render.yaml` Blueprint is configured for Render's native Python runtime and free web-service plan. Render installs the packages from `requirements.txt` and starts the Flask app with Gunicorn. The `.python-version` file pins Python to a version compatible with the TensorFlow dependency.

To deploy, connect the `samir-deshmukh/sush` GitHub repository in Render and create the service from its Blueprint. Set `GEMINI_API_KEY` only if optional Gemini image review and live guidance are wanted; built-in guidance works without it. `SECRET_KEY` is generated by Render.

**Free-service storage limitation:** Render's free web service has an ephemeral filesystem. The SQLite database (`data/predictions.db`), cached guidance, and uploaded photos can be lost when the service restarts or redeploys. This configuration does not promise permanent history or a permanent cache. Persistent data requires a separately configured persistent database/storage service.

## Optional AI key

The app has built-in fallback guidance and can run without an API key. To enable optional Gemini image review, open the local `.env` file and set `GEMINI_API_KEY` to your own key. Never commit or share `.env`.

## Data and model

- The trained model and matching label files are included in the repository.
- Local prediction history and cached disease guidance are stored in `data/predictions.db`.
- Uploaded images are stored locally under `static/uploads/`.
- Image predictions can be wrong; use appropriate agricultural guidance before making treatment decisions.

## Troubleshooting

- **Python not found:** install Python 3.11 or 3.12 and reopen the terminal.
- **Package installation fails:** check the internet connection, then run `bash setup.sh` again.
- **Port 5000 is busy:** stop the other local server, or set a different `PORT` in `.env` before starting.
